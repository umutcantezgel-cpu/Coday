# 1. Executive Summary

Dieses Dokument definiert die vollständige visuelle Identität für B2B/KMU-fokussierte digitale und analoge Medien. Die Design-DNA basiert auf einer molekularen Analyse bestehender Assets und wurde für maximale Wiederverwendbarkeit in Web Design, Marketing-Materialien, Präsentationen und Print-Medien optimiert.

## Kernprinzipien

| Prinzip | Beschreibung |
|---------|--------------|
| **Minimalismus** | Reduzierte visuelle Komplexität, Fokus auf Kernbotschaft |
| **Zugänglichkeit** | Klare, verständliche Darstellung für alle Zielgruppen |
| **Professionalität** | B2B-geeignete, seriöse Ästhetik ohne Spielerei |
| **Konsistenz** | Einheitliche visuelle Sprache über alle Touchpoints |
| **Skalierbarkeit** | Anpassbar für verschiedene Branchen und Anwendungen |

## Zielgruppenprofile

- **Primär:** KMU-Inhaber, Handwerker, lokale Dienstleister
- **Sekundär:** Marketing-Manager, Entscheidungsträger in B2B
- **Tertiär:** Endverbraucher (über B2B-Kanäle)

## 2.2 Stilistische DNA-Marker

### Flaches Design (Flat Design)

**Definition:** Zweidimensionale Darstellung ohne Schatten, Texturen oder Tiefeneffekte.

**Charakteristiken:**
- Keine Verläufe (Gradients) in Primärelementen
- Keine 3D-Effekte oder perspektivische Verzerrung
- Klare, harte Kanten ohne Weichzeichnung
- Einheitliche Farbflächen

### Gesichtslose Figuren (Faceless Figures)

**Definition:** Menschliche Darstellungen ohne detaillierte Gesichtszüge.

**Charakteristiken:**
- Hautfarbene ovale Kopfform
- Keine Augen, Nase, Mund
- Haare als Silhouette definiert
- Körpersprache transportiert Emotion

**Psychologischer Effekt:**
- Universelle Identifikation
- Keine Ablenkung durch Gesichtsdetails
- Fokus auf Aktivität/Kontext
- Inklusive Darstellung aller Ethnien

# 8. Fotografierichtlinien

### Bildbearbeitung

**Overlay-Filter:**
```css
/* Teal Overlay für Konsistenz */
.image-overlay {
    background: linear-gradient(
        135deg,
        rgba(26, 154, 154, 0.1) 0%,
        rgba(26, 154, 154, 0.05) 100%
    );
```

### Auswahlkriterien

- ✅ Helle, natürliche Beleuchtung
- ✅ Authentische Situationen
- ✅ Diverse Darstellung

# 11. Prompt-Engineering-Guide

## 11.1 Anatomie eines perfekten Prompts

```
┌─────────────────────────────────────────────────────────────┐
│                  PROMPT-STRUKTUR                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. SUBJEKT     "Professional plumber"                     │
│  2. AKTION      "fixing sink"                              │
│  3. SETTING     "in modern bathroom"                       │
│  4. STIL        "minimalist flat design illustration"      │
│  5. FARBE       "teal accent on tools and uniform"         │
│  6. FIGUR       "faceless professional figure"             │
│  7. HINTERGRUND "clean white background"                   │
│  8. KONZEPT     "professional service concept"             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 11.2 Pflicht-Keywords

**Immer einschließen:**
- `minimalist flat design illustration`
- `faceless` (für Figuren)
- `teal accent`
- `clean white background`
- `vector art aesthetic`

**Negative Prompts:**
- `blurry, low quality, distorted`
- `watermark, text, bad anatomy`
- `ugly, realistic face, photorealistic`
- `gradients, 3D render`

## 11.3 Stil-Modifikatoren

| Modifier | Effekt |
|----------|--------|
| `corporate style` | Formeller, B2B-geeignet |
| `friendly atmosphere` | Wärmer, zugänglicher |
| `dynamic composition` | Mehr Bewegung/Energie |
| `elegant minimal` | Luxuriöser, cleaner |
| `tech aesthetic` | Moderner, digitaler |

# 12. Do's und Don'ts

## 12.1 Design Do's ✅

```
✅ Konsistente Teal-Akzente verwenden
✅ Gesichtslose Figuren für Universalität
✅ Viel White Space für Klarheit
✅ Organische Formen für Wärme
✅ Klare visuelle Hierarchie
✅ Mobile-First denken
✅ Barrierefreiheit prüfen
✅ SVG für Icons verwenden
✅ Konsistente Abstände einhalten
✅ Echte Situationen darstellen
```

## 12.2 Design Don'ts ❌

```
❌ Gradienten in Hauptelementen
❌ Realistische Gesichter in Illustrationen
❌ Überladene Kompositionen
❌ Mehr als 3 Farben pro Szene
❌ Stock-Foto-Klischees
❌ Kleine, schlecht lesbare Texte
❌ Inkonsistente Icon-Styles mischen
❌ Schatten und 3D-Effekte
❌ Übermäßige Animation
❌ Texte in Bildern (außer Mockups)
```

# 15. Glossar

|---------|------------|

| **Organic Shapes** | Natürliche, unregelmäßige Formen |
